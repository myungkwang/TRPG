# 2차 프로젝트 중간 진도점검 체크리스트

**점검 일자:** 2026-06-10
**프로젝트명:** 증기와 비늘 (Steam & Scales) — AI 게임마스터 기반 텍스트 TRPG
**한 줄 소개:** 스팀펑크 세계 '재끝 마을'에서, 기억을 잃은 주인공이 NPC들과 자유롭게 대화하며 AI 게임마스터(GM)의 판정으로 스토리가 진행되고, 플레이어의 선택에 따라 엔딩이 갈리는 AI TRPG

> 각 항목은 **완료 / 진행중 / 미착수**로 표기하고 간략하게 강조식으로 작성합니다. 미착수·진행중 항목은 잔여 기간 내 자료 계획을 함께 기재합니다.

## 1. 기획 및 페르소나

- [완료] 게임 컨셉 한 줄 정의
  - "기억을 잃고 진료소에서 깨어난 주인공이, 사라진 광부의 진실을 좇아 NPC들과 자유 대화하고, AI GM이 판정·트리거로 사건을 진행시켜 선택에 따라 결말이 갈리는 스팀펑크 TRPG"

- [완료] 캐릭터(페르소나) 카드 작성 — AI GM + NPC 6인 (`personas.py` / `personas.js`, 단일 출처)
  - **AI GM(나레이터):** 정중한 존댓말 합쇼체로 장면·판정·안내를 서술. NPC 대사와 화자 분리.
  - **린**(여관 주인·구미호): 의뭉스럽고 진실과 거짓을 섞음 / 비밀: 광부 실종의 진실 일부를 앎
  - **가일**(채굴 감독): 권위적이나 겁많음 / 비밀: 실종자 수 은폐, 군용 영석 도면 보유
  - **마르타**(노파): 봉우리 전설·옛 의례를 앎
  - **토비**(소년 광부): 사라진 형을 찾는 절박함
  - **의사**(진료소): 주인공의 기억상실 원인에 대해 무언가 앎
  - **카르가스**(봉우리의 태고 드래곤): 영정의 근원과 얽힌 존재
  - 각 카드: 성격·목표·비밀·말투·아는 범위/모르는 범위(환각 방지)·관계치(-50~50)·TTS 보이스 포함

- [완료] 타깃 사용자 및 핵심 사용 시나리오 (스토리 5단계)
  - 타깃: 텍스트 RPG·AI 인터랙션에 관심 있는 게이머
  1. **도입** — 진료소 각성, 캐릭터 생성(능력치/재능/직업, 포인트 분배제)
  2. **조사** — 마을·광산 입구 조사, 단서 수집(가일·마르타·토비)
  3. **심부** — 갱도 심부 진입, 진실 접근
  4. **절정** — 봉우리에서 카르가스 대면, 채굴 중단 합의 선택(판정)
  5. **결말** — 트리거 조합으로 엔딩 분기, 에필로그 공개

- [완료] 기존 서비스 대비 차별점 명시
  - AI **툴 호출(function calling)** 로 자유 대화가 실제 게임 상태(플래그·이벤트·아이템·관계)를 바꿈 — 키워드 매칭이 아님
  - **베드 엔딩을 AI가 회차마다 생성** — 단서·합의를 놓치면 그 플레이에 맞춘 실패 결말을 LLM이 작성
  - NPC별 음성(TTS) + 3D 캐릭터 + 엔딩 일러스트로 멀티모달 연출

- [완료] 결과물 형태 및 모달리티 선정 확정
  - 텍스트 대화(화자별 말풍선) + NPC별 TTS 음성 + 3D 캐릭터(Three.js) + 엔딩 일러스트(이미지 생성)
  - LLM: OpenAI **gpt-4o-mini** (tool use) / TTS: **gpt-4o-mini-tts** / 임베딩: **text-embedding-3-small** / 이미지: **gpt-image-1**
  - DB: PostgreSQL + pgvector / 백엔드: FastAPI / 프론트: React + Vite

## 3. AI 응답 엔진

- [완료] 응답 엔진 선정 (근거 문서화)
  - **gpt-4o-mini** 채택. 근거: 함수 호출(tool use) 안정성 + 비용 효율 + 한국어 품질
  - `.env`의 `LLM_MODEL` 분리 → 모델만 바꾸면 교체 가능

- [완료] 시스템 프롬프트로 GM/NPC 응답 동작 확인 (`gm_cli.py SYSTEM_PROMPT`)
  - GM 서술 = 존댓말 나레이터체, NPC 대사 = 각 인물 말투
  - 화자 라벨(`GM:` / `의사:` / `린:` …)로 출력 → 프론트에서 화자별 말풍선 분리
  - 매 응답 끝 `[선택지]` 블록 출력 → 선택지 버튼 자동 생성(자유 입력 병행)
  - 플레이어 끼어들기(barge-in) 시 직전 맥락+입력을 함께 고려해 반응

- [완료] AI 툴 호출 파이프라인 (자유 대화 → 게임 상태 변경)
  - `roll_check`(d12 판정) / `set_flag`(진행 플래그) / `visit_event`(이벤트 통과·호감도 보상) / `set_location`(장면 전환·배경) / `give_item`(아이템)
  - 상태 변경(`progression.py`)과 엔딩 판정(`endings.py`) 모듈 분리

- [완료] RAG 파이프라인 (세계관 정본 주입)
  - 마크다운 lore 문서 → 헤더 기반 청킹 → text-embedding-3-small 임베딩 → pgvector 적재(`ingest_md.py`)
  - 매 대화마다 `retrieve_context`로 top-k 검색해 세계관 컨텍스트로 주입

- [완료] 엔진 환경변수 스위칭 구조 확보
  - `.env` — `LLM_MODEL` / `EMBEDDING_MODEL` / `IMAGE_MODEL` / `OPENAI_API_KEY` 분리

## 4. 백엔드 및 통합

- [완료] API 서버를 통한 실제 응답 호출 (모의 응답 아님)
  - LLM(gpt-4o-mini), TTS(gpt-4o-mini-tts), 이미지(gpt-image-1) **전부 실제 OpenAI 호출** 동작 확인

- [완료] 세션·대화 저장소 구축 및 데이터 적재
  - `game_sessions`(stats·flags·inventory·relations·ending JSONB), `game_events`(대화 로그), `users`(JWT 인증)
  - PostgreSQL + pgvector 구조 확정

- [완료] 엔딩 시스템 (하이브리드: 규칙 + AI)
  - **정규 엔딩(노멀/트루/히든)** = 플래그·이벤트·관계 조합의 규칙 기반 판정
  - **베드 엔딩** = 정규 미달 시 AI가 그 회차 여정을 반영해 생성(fallback)
  - 진행도 **70%에서 분기 확정(lock) + 일러스트 미리 생성** → **100%(에필로그)에서 공개**
  - `[테스트]` 디버그 엔드포인트(`/api/debug/ending`)로 4종 엔딩 즉시 점프 확인 가능

- [완료] 도감(코덱스) 계정 단위 누적 (`codex.py`, `user_codex` 테이블)
  - 해금 단서·도달 엔딩을 **회차가 바뀌어도 계정에 영구 누적**
  - 정규 엔딩은 1슬롯(중복 무시), 베드 엔딩은 회차마다 개별 항목으로 누적

- [진행중] 전체 E2E 통합 플레이테스트
  - 자료 계획: 5단계 정주행 1회 + 4종 엔딩 + 끼어들기·배경전환까지 통합 시나리오 점검

  - 비밀번호 bcrypt 해시, 토큰 기반 세션 소유 검증

  - 화자별 말풍선(색 구분: GM=청록 나레이터 / NPC=페르소나 색)
  - **선택지 자동 생성 버튼 + 자유 대화 입력 병행**
  - **음성 끼어들기(barge-in)** — AI 발화 중 입력하면 즉시 중단하고 맥락 반영해 응답

- [완료] 3D 캐릭터 / 배경 전환 / BGM
  - Three.js 기반 NPC 3D 모델, 화자에 따라 전환
  - `set_location` 도구로 장면 이동 시 배경(진료소/여관/정제소/광산) 자동 전환
  - 갱도 등 장소 BGM 연동

- [완료] 도감 패널 (인물/아이템/단서/엔딩 탭)
  - 엔딩 탭: 정규 3종은 ??? 잠금→도달 시 해금, 베드는 누적 목록으로 표시(이미지·요약 확인)

- [진행중] 지도/말판 AI 이벤트 연동 (Phaser)
  - AI가 스토리 단계를 진행시키면 말판이 자동 전진하도록 연결 완료, **트리거 빈도·연출 튜닝 진행중**
  - 자료 계획: 단계별 노드 매핑 점검 + 과도/과소 이동 보정

## 6. 평가 설계

- [완료] 평가 지표 3~5개 선정 및 가중치 설정

  | 지표 | 가중치 | 정의 | 측정 방법 |
  | ---- | ----- | ---- | -------- |
  | 페르소나·세계관 일관성 | 30% | NPC가 말투·비밀·아는 범위를 벗어나지 않는가 | LLM-as-Judge 또는 휴먼 5점 |
  | 트리거·진행 정확도 | 25% | 적절한 시점에만 set_flag/visit_event를 호출하는가 | 골든 시나리오 통과율 |
  | 엔딩 분기 정확도 | 20% | 같은 조건이 의도한 엔딩으로 수렴하는가 | 4종 엔딩 케이스 테스트 |
  | 응답 시간 | 15% | 사용자 체감 속도 | 평균/95퍼센타일 응답 ms |
  | 멀티모달 완성도 | 10% | TTS 화자 분리·엔딩 이미지 품질 | 화자 정확도·휴먼 평가 |

  **가중치 선정 근거**
  - NPC와의 대화가 핵심 경험 → **페르소나·세계관 일관성(30%)** 이 무너지면 몰입 붕괴
  - 자유 대화가 실제 진행을 바꾸는 구조 → **트리거 정확도(25%)** 가 게임성 좌우
  - "선택에 따른 분기"가 핵심 약속 → **엔딩 분기 정확도(20%)**
  - TTS·이미지·3D를 실제 통합 → **멀티모달 완성도(10%)** 측정

- [미착수] 골든 시나리오·자동 채점 스크립트
  - 자료 계획: 4종 엔딩 + 트리거 골든 케이스를 pytest 기반으로 작성, 통과율 자동 집계
