# 『증기와 비늘』 RAG 지식베이스 (lore)

AI GM이 세계관에 맞게 답하도록 **검색(RAG)에 쓰이는 설정 자료**입니다.
각 문서는 임베딩되어 pgvector에 저장되고, 플레이어 입력과 의미가 가까운 부분이 GM 컨텍스트로 전달됩니다.

## 구성
| 파일 | 내용 |
|---|---|
| `01-세계관.md` | 영석·영정·술식기계 등 세계의 기본 설정 |
| `02-지명.md` | 재끝 마을, 광산, 봉우리 등 장소 |
| `03-세력.md` | 제국 영석공사, 잿불 교단 등 세력 |
| `04-인물.md` | 주요 NPC 배경 서사 (성격 카드는 `personas.js`) |
| `05-사건.md` | 중심 미스터리 — 사라진 광부 사건 |
| `06-규칙과성장.md` | 직업·재능·판정·성장 규칙 요약 |

## 작성 규칙 (검색 품질용)
- **제목(`#`, `##`) 단위로 의미를 나눈다.** 청킹이 제목 기준으로 잘리면 검색 정확도가 오른다.
- 한 섹션은 한 주제만. 너무 길면 소제목으로 쪼갠다.
- 정확한 수치(가격·스탯)는 여기 넣지 말 것 — 그건 `items.js`/코드가 담당(정본). 여기는 **서사·설정·분위기**.

## 임베딩(적재) 방법
현재 `ingest_docx.py`는 `.docx`만 읽는다. 이 마크다운들을 적재하려면 둘 중 하나:
1. `ingest_docx.py`에 `.md/.txt` 읽기 추가 (제목 단위 청킹 권장), 또는
2. 이 폴더를 합쳐 하나의 문서로 적재.

> 적재 후 `documents.title`·`chunks.section_title`에 파일명·제목이 들어가도록 하면 출처 표시가 깔끔해진다.

## 정본 우선순위 (canon)
GM은 이 자료를 **세계관 정본으로 우선**한다. 자료에 없는 건 단정하지 말고, 톤에 맞게 작게 보완한다.
