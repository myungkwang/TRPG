# 증기와 비늘 · Steam & Scales — 프론트 프로토타입

React + Vite + Phaser 3. 모든 화면이 **임시값으로 동작**합니다.

## 실행
```bash
npm install
npm run dev
```
브라우저가 자동으로 http://localhost:5173 을 엽니다.

## 구현된 화면
- **타이틀**: 게임 시작 / 이어하기(저장 없으면 비활성) / 도감 / 설정
- **평시 대화**: 말풍선 색 구분 (GM=밤색 · 린=진홍 · 플레이어=회색), 자유 입력
- **선택지 상태**: "선택의 기회가…" 이탤릭 희미 문구 + 3선택지, 기존 대화 스크롤, 입력으로 그냥 넘기기 가능
- **판정 주사위(d12)**: 대화창 우상단. 판정 필요 시 굴림 (DC 성공/실패 표시)
- **메뉴(좌상단 육각)**: 유저정보 → [스테이터스 / 인벤토리 / 전체지도 / 도감], 저장(즉시), 설정(템플릿 없음·비활성)
- **스테이터스**: 능력치·활력·자원·전투·재능/직업
- **인벤토리**: 3×4 + 주사위 슬롯. 다중 칸 아이템, 영정/재화 10개 초과 시 칸 분할(영정 23→10·10·3)
- **도감**: 책 펼침 + 필름스트립(미발견은 ???)
- **전체지도**: 양피지 위 노드 그래프(현재=붉은 노드, 안개=미발견)
- **안갯속 지도(Phaser)**: 대화 중 [🗺 지도 트리거] → 발판 3갈래 이동, 카메라 추적, 안 고른 길 삭제, 끝에 엔딩 데포르메 노드

## 교체 포인트 (나중에)
- 캐릭터: `Dialogue.jsx`의 `.char-placeholder` → `public/lin.png` 이미지 또는 R3F/Babylon 캔버스
- 대화 응답: `Dialogue.jsx`의 `send()`/`pickChoice()` 스텁 → `fetch('/api/chat')` (FastAPI→LLM)
- 음성: TTS 오디오 받아 재생 + 립싱크
- 저장: 현재 localStorage. 서버 세이브로 교체 가능
- 설정 UI: 템플릿 확정 후 구현
- 엔딩 데포르메: `mapScene.js`의 `showEnding()` 🐉 자리 → 실제 데포르메 이미지

## 폴더
```
src/
  App.jsx            화면/오버레이 상태
  data.js            임시 데이터 (시트/서버로 교체)
  components/        Title, Dialogue, D12, Menu, Panels, MapOverlay
  game/mapScene.js   Phaser 지도 씬
```
