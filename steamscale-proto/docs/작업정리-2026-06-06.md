# 작업 정리 · 2026-06-06

증기와 비늘(Steam & Scales) 프로토타입 — 로그인/도감/지도/인벤토리 주사위 작업 정리.

## 0. 실행 방법

```bash
cd steamscale-proto
npm install      # 최초 1회
npm run dev      # 개발 서버 (기본 http://localhost:5173)
npm run build    # 프로덕션 빌드 검증
```

## 1. 로그인 / 회원가입

**흐름**: `로그인 선택창 → 로그인 / 회원가입 → 로그인 성공 시에만 타이틀(게임 시작) 진입`

- 첫 화면이 **로그인/회원가입 선택창**으로 바뀜. 로그인해야 게임 시작 화면으로 갈 수 있음.
- 회원가입: 이름 + 비밀번호 + 비밀번호 재확인 (정규식 제한 없음). 성공 시 로그인창으로 이동.
- 로그인/회원가입 모두 **뒤로가기**로 선택창 복귀. Enter 키 제출 가능.

> **저장 위치**: 백엔드가 없어 브라우저 `localStorage` 키 `steamscale_users`에 계정 저장.
> **프로토타입 전용** — 비밀번호 평문 저장, 같은 브라우저에서만 유효. 실제 서비스 시 서버/해시 필요.

- 관련 파일: `src/components/Auth.jsx`, `src/App.jsx`(`screen: 'auth'`)

## 2. 인벤토리 (가방 + 3D 주사위)

- 인벤토리 창이 **다크 가죽 가방** 디자인(뚜껑/버클/어깨끈/스티칭).
- **닫기**: 우상단 **✕ 버튼으로만** 닫힘(바깥 클릭으로는 안 닫힘).
- **주사위 드롭다운**: 가방 **바깥 우측 테두리**에 세로 알약형 탭(🎲). 클릭하면 옆으로 주사위 창이 펼쳐지고, 다시 누르면 접힘. (인벤토리 창은 고정)
- **3D 주사위(d12)**: `three.js`로 만든 진짜 정십이면체. 클릭하면 **여러 방향으로 무작위 텀블 → 감속 → 결정된 면이 정면(수직)으로 정렬**되어 결과 숫자가 보임. (판정 없이 숫자만)

- 관련 파일: `src/components/Panels.jsx`(InventoryPanel), `src/components/Dice3D.jsx`, `src/styles.css`(`.bag*`, `.dice-*`, `.d3d`)
- 조절 포인트: 칸 크기 `CELL/GAPX/GAPY`(Panels.jsx), 굴림 속도 `omega/total`(Dice3D.jsx)

## 3. 도감 (Codex) 전면 개편

- 타이틀 화면에서 **도감을 눌러도 게임에 진입하지 않고** 그 자리에서 열림.
- **4개 카테고리(책갈피 탭, 좌상단)**: `인물 · 아이템 · 해금단서 · 엔딩` (계정당 영구 개념)
- **책 레이아웃**(좌/우 페이지) + 하단 페이지 넘김.

| 카테고리 | 구성 |
|---|---|
| 인물 | 한 페이지에 한 명(좌우 2명), 초상화·설명·**평판 기반 호감 프로그레스바**. 미발견은 ??? |
| 아이템 | 좌측 **스크롤 목록**(미해금 `NO.?????`, 10개↑ 스크롤), 우측 선택 아이템 상세 |
| 해금단서 | 아이템과 동일한 목록+상세 |
| 엔딩 | 일러스트 카드(1/페이지), 클릭 시 **모달**(큰 일러스트 + 상황 요약 + 인물 각주). X/바깥 클릭 닫힘 |

- 관련 파일: `src/components/Codex.jsx`, `src/data.js`(`CODEX_CHARACTERS/ITEMS/CLUES/ENDINGS`), `src/styles.css`(`.cx2-*`)
- 참고: 일러스트는 이모지 플레이스홀더. 해금 데이터는 정적 데모(`got` 플래그) — 추후 계정별 저장으로 교체 필요.

## 4. 지도 (안갯속 길) — 핵심 변경

### 4-1. 게임 루프
```
대화(자유입력/선택지) → 판정·행동 → [종료 시] 지도 한 걸음(자동) → 대화 복귀
```
- 대화에서 행동/판정이 끝나면 **자동으로** 지도가 떠서 한 걸음 진행하고 대화로 돌아옴(임시 복귀 대사 삽입).
- 트리거: 자유대화 전송 후 / 비판정 선택 후 / **판정 모달 종료 후**. 무대 상단 `🗺 지도` 버튼은 수동 테스트용.

### 4-2. 판정 결과로 자동 이동 (플레이어가 고르지 않음)
- 갈림길 발판은 **밟기 전까지 전부 미지(`?`/`???`)** 로만 보임.
- **판정 성공/실패로 도착 발판이 정해지고** 자동 이동. (기본: 성공→`거래`, 실패→`이벤트`)
- **밟는 순간(도착)** 발판의 정체가 드러남. 안 간 길은 미지인 채 사라짐.
- 지나온(이전) 발판·연결선은 숨김.

### 4-3. 비주얼
- 발판: 평면 타원 → **3D 원기둥**. 연결선은 노드/말 **뒤**로(겹침 해결).
- 말 토큰: 체스 말 → **두건 쓴 방랑자**(망토+두건+영석 지팡이 글로우).

- 관련 파일: `src/game/mapScene.js`, `src/components/MapOverlay.jsx`, `src/App.jsx`(`runMapStep`/`onMapResult`/`journey`), `src/components/Dialogue.jsx`(`advanceOnMap`/`triggerJudge`)
- 조절 포인트: 엔딩까지 걸음 수 `maxDepth`(mapScene.js), 판정→목적지 매핑 `onSuccess/onFail`(Dialogue.jsx)

## 5. 전체 지도 (여정 기록 기반)

- 정적 SVG → **실제 여정 누적 렌더링**.
- 출발점 → 지나온 발판(정체 표시)을 **좌/중/우 분기 그대로 지그재그**로 연결.
- 안 간 갈림길/미발견은 **흐린 `???`**. 현재 위치는 붉은 원.
- 선이 텍스트를 가리지 않게 **엣지 먼저 → 노드/라벨 나중**(2패스) + 라벨 배경.
- 전체지도 패널은 **스크롤바 숨김**(스크롤 동작은 유지).
- 새 게임 시작 시 여정 초기화.

- 관련 파일: `src/components/Panels.jsx`(FullMapPanel), `src/App.jsx`(`journey`), `src/game/mapScene.js`(slot/siblingSlots 보고)
- 참고: `journey`는 메모리 상태(새로고침 시 초기화). 영구 저장하려면 `saveGame`에 포함 필요.
